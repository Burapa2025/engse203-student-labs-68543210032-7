| คอลัมน์ | ใส่อะไร | ตัวอย่างสิ่งที่เขียน *(บั๊กสมมติ)* |
|---|---|---|
| **ไฟล์ : บรรทัด** | ไฟล์ที่แก้ + เลขบรรทัด | `Foo.jsx : 12` |
| **สาเหตุ** | **ทำไม** มันทำงานผิด (ไม่ใช่แค่ "พิมพ์ผิด") | "ใส่วงเล็บท้ายชื่อฟังก์ชัน เลยถูกเรียกทันทีตอน render" |

## บันทึกของฉัน — กรอกทั้ง 6 บั๊ก

| # | อาการ (ให้มาแล้ว) | ไฟล์ : บรรทัด | สาเหตุ (ทำไมผิด) | แก้อย่างไร |
|---|---|---|---|---|
| 1 | Console เตือนสีเหลืองเรื่องรายการ (list) ที่แผงสรุป | `SummaryPanel.jsx : 12` | ในการวนลูป .map() ไม่ได้ใส่ prop key ให้กับ <article> ทำให้ React แจ้งเตือนเรื่อง unique key | เพิ่ม `key={key}` ในแท็กของ `<article className="summary-card" key={key}>` ที่ตอนแรก `<article className="summary-card">` |
| 2 | ตัวเลข "เสร็จสิ้น" ในแผงสรุปไม่ตรงกับที่เห็นจริง | `DashboardPage : 50` | ใช้เงื่อนไขกรองสถานะผิด โดยไปนับสถานะ 'in-progress' แทนที่จะนับ 'completed' แถมยังมี Syntax Error จากเครื่องหมาย quote เกิน (in-progress'') | เปลี่ยน`.filter() จาก request.status === in-progress'` ให้เป็น`request.status === 'completed'`ให้ตรงกับชื่อสถานะ |
| 3 | กดตัวกรองสถานะใด ๆ แล้วผลไม่เปลี่ยน (เหมือนกรองไม่ทำงาน) | `DashboardPage : 55` | ในตอนแรกใช้เงื่อนไข`requests.filter((request) => request.status === 'pending');` | เปลี่ยน`requests.filter((request) => request.status === 'pending');`ให้เปลี่ยนเป็น `requests.filter((request) => request.status === statusFilter);` |
| 4 | เปลี่ยน URL `REQ-101` → `REQ-102` แล้วข้อมูลไม่เปลี่ยน | `RequestDetailPage.jsx : 28` | Dependency Array ของ useEffect เป็น array ว่าง [] ทำให้ React ดึงข้อมูลแค่ครั้งแรกที่โหลดหน้า พอนาวิกเกตเปลี่ยน URL ค่า requestId เปลี่ยน แต่ useEffect ไม่ทำงานใหม่ | ใส่ `requestId` ลงใน Dependency Array เป็น `}, [requestId])`; เพื่อให้ดึงข้อมูลใหม่ทุกครั้งที่ URL เปลี่ยน |
| 5 | กด "ลบ" แล้วการ์ดหาย แต่ตัวเลขในแผงสรุปไม่ลด | `DashboardPage : 51` | `useMemo` ของ `summary` ใส่ `dependency array` เป็น `[]` ทำให้ไม่คำนวณค่าใหม่เมื่อ `requests` เปลี่ยน | ใส่ `requests` ใน `dependency array` ของ `useMemo` เป็น `}, [requests]);` |
| 6 | กด "ลบ" แล้วหน้าพัง/ว่างเปล่า | `DashboardPage : 64` | เรียกใช้ deleteRequest() ซึ่งเป็น `async function` โดยไม่ได้ใส่ `await` ทำให้ `state requests` ได้ค่าเป็น `Promise` แทน `Array` จนเกิด `runtime error` ตอน `render` | ใส่ `await` ข้างหน้าเป็น `const nextRequests = await deleteRequest(requestId);` |
